# rdkafka-1c — внешняя компонента 1С для Apache Kafka

Пакет ставит в `/opt/rdkafka-1c/`:

| Файл | Назначение |
|---|---|
| `libRdKafka1C.so` | Linux-библиотека компоненты (Native API, x86_64) |
| `RdKafka1C.zip` | пакет компоненты для 1С: библиотеки для Linux и Windows и `MANIFEST.XML` |

## Подключение в 1С

Обычно компонента поставляется в конфигурации макетом и подключается из него. Пакет нужен, чтобы
подключать её с диска сервера 1С — код ниже выполняется на сервере:

```bsl
// zip-пакет: через временное хранилище, как при подключении из макета
Адрес = ПоместитьВоВременноеХранилище(Новый ДвоичныеДанные("/opt/rdkafka-1c/RdKafka1C.zip"));
ПодключитьВнешнююКомпоненту(Адрес, "Kafka", ТипВнешнейКомпоненты.Native, ТипПодключенияВнешнейКомпоненты.Изолированно);

// или напрямую Linux-библиотеку
ПодключитьВнешнююКомпоненту("/opt/rdkafka-1c/libRdKafka1C.so", "Kafka", ТипВнешнейКомпоненты.Native, ТипПодключенияВнешнейКомпоненты.Изолированно);

Компонента = Новый("AddIn.Kafka.RdKafka1C");
```

После обновления пакета перезапустите рабочие процессы 1С: уже загруженная компонента остаётся в памяти.
Если конфигурация подключает компоненту из макета, пакет rpm на неё не влияет — обновляется макет.

## Зависимости

- glibc 2.34+ и libstdc++ (RHEL/Oracle Linux/Rocky/Alma 9 и новее);
- `cyrus-sasl-lib` (`libsasl2.so.3`) — ставится автоматически;
- локаль `ru_RU` (`glibc-langpack-ru` или `glibc-all-langpacks`) и конвертер ISO-8859-5 (`glibc-gconv-extra`) —
  ставятся автоматически. Компонента переключает
  процесс на `ru_RU` и через неё переводит строки из 1С: без локали кириллические идентификаторы сообщений,
  имена топиков и параметры превращаются в пустые строки (сообщения уходят, но `СтатусСообщения` = NOT_PERSISTED);
- OpenSSL, librdkafka, Boost, lz4, zstd и zlib вшиты в библиотеку статически: обновления этих пакетов
  в ОС на компоненту не влияют, обновляется только сам пакет rdkafka-1c. Их лицензии —
  в `/usr/share/licenses/rdkafka-1c/third-party/`.

Для Kerberos (SASL GSSAPI) поставьте пакет `rdkafka-1c-kerberos` — см. его README.
